# 상담자료실 개편 계획

Last updated: 2026-07-10 KST

## 1. 목적

상담자료실은 단순 링크 모음이 아니라 특성화고 학생, 선생님, 행정직원이 바로 찾고, 열고, 출력하고, 상담 답변에 활용할 수 있는 공식 자료 창고가 되어야 한다. 최종 목표는 다음 세 가지다.

- 특성화고 현장실습, 취업지도, 학생생활, 학교행정, 안전, 개인정보, 교직원 복무 자료를 한곳에서 찾게 한다.
- 자료는 검색 대행이 아니라 원문 파일, 법령 원문, 상세 자료 페이지로 바로 연결한다.
- 자료 확보 자동화와 사용자 화면을 함께 개선해 자료량이 늘어도 사용자가 길을 잃지 않게 한다.

### 현재 수집 체계

현재 자동 수집기는 다음 축으로 움직인다.

- `tools/public-resource-autopilot.mjs`: 공식 출처 목록, 검색어, 게시글 상세, 첨부파일 추출.
- `tools/build-public-resource-index.mjs`: 직접 열 수 있는 자료만 공개 인덱스로 승격.
- `tools/verify-public-resource-artifacts.mjs`: 구글 검색 링크, 기관 메인, 게시판 목록, 깨진 법령 링크 차단.
- `npm run policy:resources:scheduled`: 하루 3회 자동 수집을 위한 전체 파이프라인.

현재 보호선은 공개 자료 1,000건 이상, 직접 파일 1,000건 이상, 지침 330건 이상, 서식 650건 이상, 하이파이브 자료 80건 이상이다.

### 화면 현황

캡처 파일:

- `output/resource-library-plan/01-desktop-resource-library.png`
- `output/resource-library-plan/02-mobile-resource-library.png`

확인된 장점:

- 로그인 없이 자료실이 보인다.
- 자료유형, 대분류, 중분류, 세부자료 4단계 분류가 있다.
- 단어 4개를 분리 입력해 AND 검색처럼 쓸 수 있다.
- 화면 문구가 "공식 원문·파일" 중심으로 되어 있어 신뢰 방향은 맞다.

확인된 문제:

- 모바일 첫 화면에서 자료실까지 도달하기 전에 상담실 카드가 길게 보인다. 자료실 사용자가 바로 자료를 찾기 어렵다.
- 1,000건이 넘는 자료를 드롭다운 중심으로 탐색하게 되어, 사용자가 어느 분류부터 눌러야 할지 판단 부담이 크다.
- "법률, 규정, 지침, 서식"이라는 자료유형은 좋지만, 특성화고 사용자는 보통 "현장실습", "학교폭력", "생활기록부", "계약제교원", "학교회계"처럼 업무 상황으로 찾는다.
- 현재 목록은 제목·설명·출처가 길어 자료의 중요도, 최신성, 다운로드 형식, 원문 신뢰도를 한눈에 비교하기 어렵다.
- 생성 인덱스 1,131건과 화면 표시 1,155건이 차이난다. 앱이 생성 인덱스에 정적 큐레이션 자료를 병합하기 때문이다. 이 구조는 괜찮지만, 운영 통계와 화면 통계가 같은 기준으로 표시되도록 정리해야 한다.

## 3. 공식 출처 분석

### 이미 경쟁력 있는 출처

- 교육부·하이파이브: 직업계고, 현장실습, 취업·진로, 취업지원, 고교 취업연계 장려금, 현장실습 지원금 등 특성화고 핵심 메뉴를 갖고 있다.
- 경북교육청 학교지원종합자료실: 관련 서식이 본문형 콘텐츠 안에 풍부하게 들어 있어 서식창고로 활용 가치가 높다.
- 학교생활기록부 종합지원포털: 학교생활기록부 기재요령을 연도별, 학교급별로 제공한다.
- 국가법령정보센터: 법령과 행정규칙 원문 연결의 기준 출처다.

### 추가 확보가 필요한 출처군

1. 시도교육청별 자료실
   - 경북 중심에서 전국 17개 시도교육청으로 확장한다.
   - 우선순위: 학교생활, 민주시민/인성, 진로직업, 체육건강, 학교회계, 노사협력, 개인정보, 감사자료.

2. 직업계고 특화 출처
   - 하이파이브 자료실을 유지하되, 검색어 기반이 아니라 메뉴 기반 크롤링으로 전환한다.
   - 직업계고 학점제, NCS, 과정평가형 자격, 도제학교, 직업교육 혁신지구, 채용연계형 직무교육과정 자료를 별도 선반으로 만든다.

3. 안전·보건 출처
   - 안전보건공단, 학교안전공제중앙회, 교육부 학교안전 자료를 분리 수집한다.
   - 특히 실습실, 기계·기구, 화학물질, 위험성평가, 산업안전보건교육 자료는 특성화고 경쟁력 자료가 된다.

4. 취업·진로 출처
   - 현재 13건으로 가장 약하다.
   - 하이파이브 취업지원, 중앙취업지원센터, 고용24, 잡알리오, 산업인력공단, 직업기초능력평가, NCS 관련 자료를 직접 파일 중심으로 확보한다.
   - 채용공고와 자료실은 분리한다. 자료실에는 "지원정책, 지도자료, 면접·자기소개서, 취업추천, 근로계약, 졸업생 사후관리"를 넣는다.

5. 서식 추출 대상
   - 이미 서식 추출 후보가 734건 있다.
   - 다음 단계는 원문 파일에서 붙임·별지·부록을 분리해 PDF와 DOCX로 제공하는 것이다.

## 4. 자료 확보 개편안

### 4.1 수집 구조를 3층으로 개편

1. 출처 레지스트리
   - 공식 기관, 게시판 URL, 검색 파라미터, 상세 페이지 패턴, 첨부파일 패턴을 구조화한다.
   - 출처마다 `owner`, `coverage`, `risk`, `refreshCycle`, `parserType`을 기록한다.

2. 수집 어댑터
   - `education-office-board`: 시도교육청 표준 `selectNttList/selectNttInfo` 계열.
   - `content-page`: 학교지원종합자료실처럼 본문형 콘텐츠와 다운로드 버튼이 있는 구조.
   - `hifive-bbs`: 하이파이브 게시판 구조.
   - `law-detail`: 국가법령정보센터 법령·행정규칙 상세.
   - `file-direct`: 직접 파일 URL 검증.

3. 공개 색인
   - 사용자가 볼 수 있는 자료만 승격한다.
   - 검색 대행, 기관 메인, 게시판 목록, 홍보물, 공모전, 인사발령, 채용공고는 차단한다.

### 4.2 우선 확보 로드맵

#### 1차: 취업·진로 강화

목표: 취업·진로 자료 13건을 100건 이상으로 확대.

포함 자료:

- 고졸채용기업 지원정책
- 고졸청년 지원정책
- 취업추천 운영 자료
- 자기소개서, 이력서, 면접 지도 서식
- 근로계약, 임금체불, 졸업생 사후관리 자료
- 직업기초능력평가, NCS, 직무역량 자료

검증선:

- 취업·진로 자료 100건 이상
- 하이파이브 취업지원 직접 파일 30건 이상
- 자기소개서·면접·취업추천 서식 20건 이상

#### 2차: 전국 교육청 확장

목표: 경북 편중을 낮추고 전국 교육청별 지침·서식을 확보.

우선순위:

- 서울, 경기, 인천, 부산, 대구, 대전, 광주, 울산, 세종, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주

수집 주제:

- 현장실습·직업교육
- 학교폭력·생활지도
- 현장체험학습
- 학교회계·계약·강사수당
- 교직원 복무·계약제교원·교육공무직
- 개인정보·정보공개·기록물

검증선:

- 17개 교육청 중 10개 이상에서 직접 파일 확보
- 특정 교육청 자료 비중 70% 이하
- 교육청별 최신 연도 자료 우선 표시

#### 3차: 서식 분리 산출물

목표: 원문 지침 안의 서식을 별도 PDF/DOCX로 제공.

처리 흐름:

1. HWP/HWPX/PDF 원문 다운로드.
2. 붙임, 별지, 서식 제목과 페이지 범위 탐지.
3. 서식 단위로 PDF 생성.
4. 편집 가능한 DOCX 생성.
5. 원문 출처, 원문 파일 URL, 추출 일시, 검증 상태 기록.
6. 렌더링 검증 통과 시 공개.

검증선:

- 분리 서식 200건 이상
- PDF/DOCX 쌍 제공률 90% 이상
- 표 깨짐, 글자 잘림, 빈칸 누락 검출 실패 시 비공개

#### 4차: 관리자 큐레이션 레이어

목표: 자동 수집 자료를 "현장 추천 자료"로 가공.

기능:

- 즐겨찾기/대표 자료 지정
- "선생님이 자주 찾는 자료" 선반
- "학생에게 바로 안내 가능한 자료" 선반
- 오래된 자료 경고
- 교육청별 적용 여부 표시
- 상담 답변에 첨부하기 버튼

## 5. UI 개편안

### 5.1 첫 화면 구조

현재는 상담실이 먼저 길게 나오고 자료실은 아래에 있다. 자료실 중심 사용자는 진입이 늦다.

개편안:

1. 상담자료실 상단에 두 개의 큰 탭을 둔다.
   - `자료 찾기`
   - `상담실`

2. 기본 첫 화면은 `자료 찾기`로 둔다.
   - 로그인 없이 쓰는 기능이므로 진입 장벽이 낮다.
   - 상담실은 로그인과 승인 흐름이 있어 별도 탭으로 분리한다.

3. 첫 화면 최상단에 "자주 찾는 업무 바로가기"를 둔다.
   - 현장실습
   - 생활기록부·출결
   - 학교폭력·생활지도
   - 학교회계·계약
   - 계약제교원·복무
   - 개인정보·정보공개
   - 취업·진로
   - 서식창고

### 5.2 탐색 방식

현재의 4단계 드롭다운은 정교하지만, 초보 사용자에게 부담이 크다.

개편안:

- 1차 탐색: 업무 카드
- 2차 탐색: 자료유형 칩
- 3차 탐색: 고급 필터 접기/펼치기
- 4차 탐색: 단어 검색

예시:

```text
무엇을 찾나요?
[현장실습] [생활기록부] [학교폭력] [학교회계] [복무·노무] [취업·진로] [서식만 보기]

자료유형
[전체] [서식] [지침] [규정] [법률]

단어 검색
[현장실습] [표준협약서] [안전] [서식]  검색
```

### 5.3 목록 카드 개선

현재 목록은 제목과 설명이 길어 비교가 어렵다.

자료 카드에는 다음 정보를 고정 순서로 표시한다.

- 자료명
- 최신 연도
- 자료유형: 법률/규정/지침/서식
- 파일형식: PDF/HWP/HWPX/DOCX/XLSX
- 출처기관
- 적용범위: 전국/경북/충북/교육부/기관별
- 상태: 바로열기/미리보기/서식추출 준비/구버전 주의
- 주요 행동: 원문 열기, 다운로드, 상담 답변에 첨부

### 5.4 미리보기 패널 개선

현재 미리보기는 선택한 자료의 요약과 링크를 보여 주는 구조다. 다음을 추가한다.

- "이 자료가 필요한 상황"
- "상담 답변에 넣을 때 주의할 점"
- "관련 자료 5개"
- "같은 주제의 최신 자료"
- "서식 추출 가능 여부"
- "교육청별 다른 버전 있음"

### 5.5 모바일 개선

모바일에서는 다음이 필요하다.

- 상단 상담실 카드보다 자료 찾기 바로가기 우선 노출
- 드롭다운 4개를 한꺼번에 보여주지 않고, "필터 열기" 바텀시트로 전환
- 검색어 입력칸은 4개 대신 한 줄 입력 + 추천 단어 칩
- 목록과 미리보기는 한 화면에서 동시에 보여주지 않고, 자료 선택 시 상세 화면으로 전환

## 6. 검색 경험 개편

### 현재 방식

- 단어 1~4를 입력해 검색.
- 선택 분류와 자료유형이 함께 적용된다.

### 개선 방향

1. 동의어 사전
   - 현장실습 = 실습, 산업체 현장실습, 직업계고 현장실습
   - 생기부 = 생활기록부, 학교생활기록부
   - 학폭 = 학교폭력, 사안처리, 전담기구
   - 복무 = 휴가, 병가, 공가, 근무상황

2. 자동 추천
   - 검색어를 입력하면 관련 업무 카드와 자료유형을 제안한다.
   - 예: "표준협약서" 입력 시 현장실습·서식 자동 선택.

3. 랭킹
   - 최신 연도 우선
   - 직접 파일 우선
   - 교육부/법령/시도교육청 공식 자료 우선
   - 서식 검색일 때 HWP/HWPX/DOCX 우선
   - 상담 답변에 자주 쓰는 자료 우선

## 9. 결론

현재 자료실은 "공식자료 직접 연결형 자료실"의 기반은 갖추었다. 다음 경쟁력은 자료 수를 더 늘리는 것만이 아니라, 다음 세 가지를 동시에 달성하는 데 있다.

1. 취업·진로와 현장실습처럼 특성화고 고유 영역을 두껍게 만든다.
2. 전국 교육청별 지침과 서식을 확보해 경북 편중을 줄인다.
3. 사용자가 업무 상황으로 찾아가고, 필요한 자료를 바로 열고, 상담 답변에 붙일 수 있게 한다.

따라서 다음 개편의 우선순위는 `UI 정보구조 개편 → 취업·진로 자료 강화 → 전국 교육청 확장 → 서식 분리 산출물 → 관리자 큐레이션` 순서가 적절하다.

## 10. 실행 기준

자료실 개편은 다음 기준을 통과한 자료만 공개하는 방식으로 진행한다.

- 검색 엔진 검색 결과 링크는 공개 자료로 인정하지 않는다.
- 기관 게시판 첫 화면으로만 연결되는 링크는 대표 자료로 인정하지 않는다.
- 법령은 국가법령정보센터 원문으로, 지침과 서식은 원문 파일 또는 해당 문서 상세 페이지로 연결한다.
- 파일명만으로 분류하지 않고 제목, 본문 요약, 출처 기관, 첨부 파일명을 함께 점수화한다.
- 특성화고 핵심 업무인 현장실습, 취업지도, NCS, 직업기초능력, 산업안전, 학적, 학생생활, 학교폭력, 개인정보, 학교회계 자료는 우선 수집 대상으로 둔다.
- 자료가 중복될 경우 최신 연도, 상위 기관, 원문 파일이 있는 항목을 우선한다.
- 화면에는 대표 자료를 먼저 보여 주되, 탭과 검색에서는 전체 자료를 빠짐없이 탐색할 수 있게 한다.

이 기준을 적용하면 자료실은 단순 자료량 경쟁이 아니라, "교사가 오늘 바로 업무에 쓰고, 학생 상담에 붙이고, 필요하면 출력할 수 있는 자료창고"를 목표로 개편된다.
