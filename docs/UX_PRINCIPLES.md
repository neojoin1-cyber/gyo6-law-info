# 사용자 편의성 설계 원칙

## 목표

`GYO6 Law Info`는 법률을 잘 모르는 학생, 선생님, 학부모도 질문을 시작할 수 있어야 한다. 복잡한 법률 검색을 사용자에게 떠넘기지 않고, 상황을 정리하고 원문으로 이어주는 흐름을 만든다.

## 첫 화면 원칙

- 홍보형 랜딩 페이지보다 바로 질문할 수 있는 작업 화면을 우선한다.
- 사용자는 질문 입력 전에 긴 설명을 읽지 않아도 된다.
- 법률 자문이 아니라 정보 제공이라는 고지는 항상 보인다.
- 사용자가 자신의 관점을 고를 수 있게 한다.
- 공식 출처가 어디인지 첫 화면에서 알 수 있게 한다.

## 입력 흐름

1. 사용자가 자연어 질문을 쓴다.
2. 사용자 관점을 고른다.
3. 질문 유형을 고르거나 자동 분류를 둔다.
4. 원하는 자료 범위를 체크한다.
5. 결과에서 원문 링크, 추천 검색어, 확인 순서를 받는다.

## 사용자 관점별 편의성

### 학생

- 어려운 법률 용어를 줄인다.
- 권리 보호, 안전, 근로조건, 학교에 요청할 자료를 먼저 보여준다.
- 학교나 선생님에게 물어볼 질문 형태를 제안한다.

### 선생님

- 상담 기록, 지도 절차, 교육청 안내, 학교 규정을 함께 확인하게 한다.
- 민원 대응 문구는 단정형보다 확인형으로 안내한다.
- 학생 보호와 교사의 절차 준수를 함께 다룬다.

### 학부모

- 절차와 기관 역할을 쉽게 설명한다.
- 학교와 대화할 때 확인할 자료를 정리한다.
- 감정적으로 민감한 사안에서는 원문과 전문가 안내를 분명히 한다.

### 학교 관리자

- 학교장, 교육청, 산업체, 외부 기관의 역할을 나눈다.
- 중대재해, 학교폭력, 인사·노무, 민원 대응을 분리한다.
- 책임 판단보다 확인 자료와 절차를 먼저 보여준다.

### 행정직원

- 계약, 복무, 기록, 행정절차 중심으로 자료를 정리한다.
- 근로관계와 교육공무원·사립학교 규정의 차이를 표시한다.

## 결과 화면 원칙

- 첫 줄에 결론처럼 보이는 판단을 쓰지 않는다.
- "요약 초안"과 "원문 확인"을 분리한다.
- 검색어를 복사하기 쉽게 짧은 태그로 제공한다.
- 공식 출처 링크는 버튼으로 제공한다.
- 체크리스트는 3단계 안팎으로 유지한다.

## 모바일 원칙

- 제목은 두세 줄 안에서 자연스럽게 줄바꿈한다.
- 버튼은 한 손으로 누르기 쉬운 높이를 유지한다.
- 선택 항목은 한 줄에 너무 많이 넣지 않는다.
- 긴 표보다 카드와 짧은 목록을 쓴다.

## 접근성 원칙

- 모든 입력에는 `label`을 둔다.
- 결과 영역은 `aria-live`로 갱신을 알린다.
- 버튼과 링크 텍스트는 목적이 드러나게 쓴다.
- 색만으로 상태를 구분하지 않는다.
- 모바일 320px 폭에서도 가로 스크롤이 생기지 않게 한다.
