# GYO6 Law Info 공식 법률자료 연결 체크리스트

이 문서는 법제처 법령 원문 이후, 판례·행정해석·절차자료를 신뢰성 있게 붙이기 위한 진행표입니다.

## 현재 완료

- 법제처 OC 인증키 확보
- Cloud Run 법제처 게이트웨이 배포
- Cloudflare Worker와 Cloud Run 게이트웨이 연결
- 현행 법령 원문 조문 조회
- AI 답변·보고서에 확인된 조문 근거 우선 반영
- 고용노동부 법령해석·법령해석례 후보 조회용 게이트웨이 코드 준비

## 지금 사용자 확인이 필요한 것

### 1. 사법정보공유포털 API

메일함에서 아래 항목을 확인합니다.

- 승인 여부
- 담당자 회신 메일
- API 신청서 또는 추가 서류 요청
- 제공 가능한 항목: 사건번호, 법원명, 선고일, 사건명, 판결요지, 참조조문, 원문 링크
- 저장·캐싱·AI 요약 허용 범위
- 일일 호출 제한과 이용 기간

승인 메일이 오면 아래 값만 로컬 `.env.local`에 정리합니다.

```env
SCOUT_API_KEY=발급받은_사법정보공유포털_키
SCOUT_API_BASE_URL=제공받은_API_BASE_URL
```

키 값은 채팅에 붙여넣지 않습니다.

### 2. 국회법률도서관 API

마이페이지 또는 신청 화면에서 아래 항목을 확인합니다.

- 승인 상태
- 인증키 발급 여부
- 서비스 이용 IP 제한 여부
- 검색 가능 자료 범위: 판례, 법률문헌, 주석서, 학술자료, 입법자료
- 화면 표시와 AI 요약 허용 범위

승인되면 아래 값만 로컬 `.env.local`에 정리합니다.

```env
NANET_API_KEY=발급받은_국회법률도서관_키
NANET_API_BASE_URL=제공받은_API_BASE_URL
```

### 3. 판례 출처 우선순위

판례는 다음 우선순위로 연결합니다.

1. 사법정보공유포털 공식 API
2. 국회법률도서관 API에서 허용되는 판례·문헌 자료
3. 공식 원문 링크 후보
4. 승인 전에는 "판례 확인 필요"로만 표시

## 다음 구현 순서

1. Cloud Run 게이트웨이 재배포로 행정해석 엔드포인트 활성화
2. Worker 검색 결과에 행정해석 후보 표시
3. 사법정보공유포털 승인 후 판례 게이트웨이 추가
4. 국회법률도서관 승인 후 보조 판례·문헌 검색 추가
5. AI 보고서에 법령 근거, 행정해석, 판례 근거를 분리 표시
6. 판례가 없을 때는 판례 내용을 추정하지 못하게 회귀 테스트 추가

## 운영 원칙

- 원문 또는 승인 API 결과가 없는 판례는 사실처럼 쓰지 않습니다.
- 판례 제목·사건번호·선고일·법원명 중 하나라도 불명확하면 "확인 필요"로 낮춥니다.
- AI 요약은 판례 원문 또는 공식 요지와 함께 표시합니다.
- 저장·캐싱은 제공기관 약관에서 허용된 범위 안에서만 적용합니다.
