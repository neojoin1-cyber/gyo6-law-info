# Public Resource Quality Strategy

Last updated: 2026-07-09 KST

## 목적

상담자료실은 특성화고 선생님과 학생이 바로 열어 볼 수 있는 공식 자료 창고여야 한다. 자료 수는 중요하지만, 연결되지 않거나 검색어만 대신 입력해 주는 자료는 신뢰를 떨어뜨리므로 공개 자료실에 올리지 않는다.

## 공개 금지 기준

- Google, Naver 등 범용 검색 결과 링크
- 공식 사이트 검색창이나 단순 게시판 목록으로만 이동하는 링크
- `law.go.kr/법령/산업안전보건법및실습실안전관리기준`처럼 실제 법령명이 아닌 조합형 주소
- 블로그, 카페, 개인 자료, 출처 불명 요약
- 제목은 그럴듯하지만 원문·파일·상세 페이지가 확인되지 않은 자동 확보 후보
- "원문 후보", "검색 후보", "확인 필요" 상태의 자료

## 공개 가능 기준

- 국가법령정보센터의 실제 법령·행정규칙 원문
- 교육부, 시도교육청, 학교생활기록부 종합지원포털, 하이파이브, 안전보건공단, 학교안전공제중앙회 등 공식 기관의 상세 페이지
- PDF, HWP/HWPX, DOCX, XLSX 등 직접 열리는 공식 파일
- 게시판 목록이 아니라 특정 게시글·자료 상세 페이지로 연결되는 공식 URL
- 제목, 출처, 자료 유형, 주제 분류가 정리된 자료

## 자동 확보 흐름

1. `tools/public-resource-autopilot.mjs`
   - 주제별 확보 목표를 점검한다.
   - 부족한 영역의 후보를 만든다.
   - 직접 URL이 없는 후보는 내부 수집 계획에만 남긴다.

2. `tools/build-public-resource-index.mjs`
   - 직접 열 수 있는 자료만 공개 색인으로 승격한다.
   - 검색-only 자료, 일반 게시판, 깨진 법령 주소를 차단한다.
   - 법령 제목은 실제 법령명으로 정규화한다.

3. `tools/verify-public-resource-library.mjs`
   - 브라우저에서 자료실을 열어 직접 법령 링크와 검색 금지 기준을 확인한다.

4. `npm run check`
   - 공개 색인에 `google.com/search`, 검색 후보 문구, 잘못된 법령 주소가 들어가면 실패한다.

## 운영 방향

- 자료량 확대는 내부 후보 큐에서 적극적으로 진행한다.
- 공개 자료실은 검증된 직접 자료만 보여 준다.
- 자동 수집이 직접 URL을 찾지 못하면 사용자에게 노출하지 않고, 다음 수집·검증 대상으로 남긴다.
- 자료실의 경쟁력은 "많은 검색 링크"가 아니라 "선생님이 바로 열어 출력·다운로드할 수 있는 정리된 공식 자료"로 만든다.

## 자료량 확대 우선순위

1. 지침과 매뉴얼
   - 교육부, 고용노동부, 시도교육청, 학교안전공제중앙회, 안전보건공단, 한국산업인력공단, 하이파이브의 공식 파일을 우선한다.
   - 특성화고 현장실습, 직업계고 학점제, NCS, 취업지원, 실습실 안전, 학교폭력, 학교회계, 교직원 복무, 개인정보, 정보공개 자료를 핵심 영역으로 본다.

2. 서식
   - 독립 서식 파일뿐 아니라 지침의 붙임, 별지, 부록, 표준서식, 체크리스트를 수집 대상으로 본다.
   - 공개 자료실에는 원문 파일을 먼저 올리고, 추출 대상은 `서식 추출 준비` 상태로 관리한다.

3. 교육청별 차이
   - 같은 주제라도 시도교육청별 서식과 운영 지침이 다를 수 있으므로, 경북 기준을 시작점으로 삼되 다른 교육청의 직접 첨부파일 수집기를 계속 확장한다.
   - 학교 현장 적용성이 낮은 홍보물, 공모전, 소식지, 단순 사례집, 채용 공고, 인사발령은 공개 자료실에서 제외한다.

## 서식 분리 품질 기준

지침 파일 내부의 서식을 PDF/DOCX로 분리할 수는 있지만, 자동 추출물이 곧바로 공개되면 안 된다. 공개 조건은 다음과 같다.

- 원문 공식 파일을 함께 보존한다.
- 추출 위치와 원문 출처를 기록한다.
- PDF는 미리보기와 출력에 적합해야 한다.
- DOCX는 편집 가능해야 하며 표, 빈칸, 체크박스가 깨지지 않아야 한다.
- 렌더링 검증에서 글자 잘림, 겹침, 표 너비 붕괴가 없어야 한다.
- 검증을 통과하지 못한 산출물은 원문 자료만 공개하고 분리본은 내부 대기열에 남긴다.
