# MVP Plan

## 핵심 사용자 흐름

1. 사용자가 생활 속 질문을 입력한다.
2. 시스템이 관련 키워드와 법령 검색 링크를 제안한다.
3. 사용자가 원문을 확인한다.
4. AI 요약은 "정보 제공" 범위에서 쉬운 말로 정리한다.
5. 중요한 사안은 전문가 상담 안내를 함께 보여준다.

## 1차 기능

- 질문 입력
- 관심 범위 선택: 법령, 판례, 행정자료
- 법제처 원문 검색 링크
- 쉬운 말 요약 자리
- 정보 제공 고지

## 2차 기능

- 법제처 Open API 연동
- 검색 결과 정렬
- 원문 링크 정확도 개선
- AI 요약 연결
- 비용 제한 및 일일 사용량 제한

## 표현 원칙

- "법률정보"라고 표현한다.
- "법률상담", "승소 가능성", "법적 판단 확정" 같은 표현은 피한다.
- 모든 답변에 원문 확인과 전문가 상담 안내를 포함한다.
