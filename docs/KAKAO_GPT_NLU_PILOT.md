# Kakao GPT NLU Pilot

## Purpose

카카오톡 챗봇에서 들어오는 자유 질문을 바로 답변 생성에 쓰지 않고, 먼저 짧은 발문 정리 단계로 통과시킨다.

목표는 다음과 같다.

- 장황하거나 무질서한 질문의 핵심 요지 정리
- 규정 도메인 후보 추출
- 신분, 교육청, 학교급, 기간, 업무 단계, 증빙, 위험 신호 슬롯 추출
- 부족한 슬롯이 있으면 단정 답변 대신 추가 질문으로 전환
- 정답 문장은 기존 규정 지식베이스와 공식 출처 엔진이 만들도록 유지

## Budget

파일럿 운영 예산은 월 30,000원 수준으로 둔다.

- 환율 가정: 1 USD = 1,500 KRW
- 경고선: 10 USD
- 차단선: 20 USD
- 기본 저비용 NLU 모델 후보: `gpt-5.4-nano`
- 재시도 또는 어려운 질문 후보: `gpt-5.4-mini`

환경 기본값:

```text
OPENAI_KRW_PER_USD=1500
OPENAI_MONTHLY_WARN_USD=10
OPENAI_MONTHLY_STOP_USD=20
OPENAI_DAILY_CALL_LIMIT=1000
KAKAO_GPT_NORMALIZER_ENABLED=true
KAKAO_GPT_NORMALIZER_MODE=auto
KAKAO_GPT_NORMALIZER_MIN_CONFIDENCE=0.82
KAKAO_NLU_MODEL=gpt-5.4-nano
KAKAO_NLU_FALLBACK_MODEL=gpt-5.4-mini
```

실제 카드 청구 차단은 OpenAI 대시보드의 프로젝트 예산 제한에도 같은 금액을 설정해야 한다.

## Privacy Gate

카카오톡 질문에는 학생, 교사, 학교, 실습기업, 민원인 정보가 포함될 수 있다. 2026-06-13 파일럿 승인 후 GPT 발문 정리 기능은 자동 모드로 활성화한다.

외부 API 호출 운영 조건:

- 사용자에게 AI 발문 정리 사용과 외부 처리 가능성을 안내한다.
- 전화번호, 이메일, 주민등록번호 등 직접 식별자 제거
- 학생명, 교사명, 학교명, 회사명 등 조직·개인 식별 표현은 답변 품질과 출처 확인에 필요한 범위에서만 사용한다.
- GPT 사용량 장부에는 원문 질문을 저장하지 않고 호출 수, 토큰 수, 추정 비용만 기록한다.
- 예산 초과 시 자동 비활성화
- GPT 결과는 답변 근거가 아니라 분류·슬롯 후보로만 사용

## Intended Flow

1. 카카오톡 질문 수신
2. 기존 규칙 엔진으로 1차 분류
3. 규칙 엔진 신뢰도가 충분하면 GPT 호출 없이 답변
4. 신뢰도 낮음, 장문, 모호 표현, 위험 신호가 있으면 GPT NLU 후보 호출
5. 정리된 질문과 슬롯으로 정책 엔진 재조회
6. 공식 출처·교육청·학교 규정 필요 여부를 표시
7. 부족한 슬롯이 있으면 카카오 빠른응답으로 추가 질문 제공

## Non-Goals

- GPT가 규정 정답을 단독 생성하지 않는다.
- GPT가 조문, 금액, 신고 의무, 판례를 추정해 만들지 않는다.
- 교육청 자료실이나 취업지원센터 자료를 1차 공식 공고처럼 노출하지 않는다.
