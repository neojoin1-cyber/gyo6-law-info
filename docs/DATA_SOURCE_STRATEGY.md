# 데이터 출처 전략

확인일: 2026-05-30

이 문서는 `GYO6 Law Info`가 공식 원문 중심으로 작동하기 위한 데이터 출처와 연결 순서를 정리한다.

## 기본 원칙

- 법률 자문이나 사건 판단을 하지 않는다.
- 법령, 판례, 행정자료, 학교 현장 지침을 출처별로 구분한다.
- 검색 결과에는 항상 원문 링크와 확인일을 표시한다.
- AI 요약은 원문 내용을 쉽게 풀어 쓰는 보조 기능으로 제한한다.
- 원문이 없거나 출처가 불명확한 내용은 답변하지 않고 추가 확인을 안내한다.

## 1순위 출처

| 구분 | 출처 | 용도 | URL |
| --- | --- | --- | --- |
| 법령·조문 | 국가법령정보센터 | 현행 법령, 조문, 시행일, 별표·서식 확인 | https://www.law.go.kr |
| 법령 API | 국가법령정보 공동활용 | 법령 목록·본문, 행정규칙, 자치법규, 판례, 헌재결정례, 법령해석례 API 연동 | https://open.law.go.kr/LSO/openApi/guideList.do |
| 판례·사법 API | 사법정보공유포털 | 법원 공공데이터 API 검토 | https://openapi.scourt.go.kr/ |
| 학교폭력 | 교육부 학교폭력 사안처리 가이드북 | 학교폭력 절차와 학교 현장 안내 | https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=316&boardSeq=98297&lev=0&m=0302&opType=N&s=moe&statusYN=W |
| 교육 정책 자료 | 교육부 | 현장실습, 도제학교, 학교 운영 관련 공식 자료 확인 | https://www.moe.go.kr/main.do?s=moe |

## 보조 출처 후보

- 고용노동부: 근로기준, 산업안전보건, 노동관계 자료
- 안전보건공단: 산업안전보건 해설 자료
- 학교안전공제중앙회: 학교안전사고 관련 안내 자료
- 시도교육청: 지역별 학교폭력, 현장실습, 민원 처리 지침
- 국회법률도서관: 법률 이슈, 입법자료, 판례 검색 보조

보조 출처는 공식 기관 여부, 최신성, 원문 링크, 저작권 조건을 확인한 뒤 연결한다.

## 데이터 연결 순서

### 1단계: 정적 검색 링크

현재 MVP 단계에서는 질문과 주제 사전을 바탕으로 공식 검색 링크를 생성한다.

- 국가법령정보센터 검색
- 법원 판례 검색
- 교육부 자료 확인
- 학교폭력 가이드북 직접 연결

### 2단계: 법제처 Open API

법령 API 키가 준비되면 다음 순서로 붙인다.

1. 법령 목록 조회
2. 법령 본문 조회
3. 조항호목 조회
4. 행정규칙 조회
5. 판례 목록·본문 조회
6. 법령해석례 조회
7. 법령용어 조회
8. 지능형 법령검색 API 검토

### 3단계: 판례·행정자료 확장

- 사법정보공유포털 API 활용 가능 범위 확인
- 교육부·교육청 자료 검색 방식 정리
- 고용노동부와 안전보건공단 자료 연결 검토

### 4단계: AI 요약

AI 요약은 다음 조건을 만족할 때만 제공한다.

- 원문 제목과 URL이 있다.
- 법령명, 조문, 시행일을 표시할 수 있다.
- 요약과 원문 근거를 분리해 보여줄 수 있다.
- 답변 끝에 정보 제공 안내를 표시한다.

## 결과 화면에 표시할 정보

- 질문 원문
- 사용자 관점: 학생, 선생님, 학부모, 학교 관리자, 행정직원
- 관련 주제
- 우선 확인할 법령·자료
- 추천 검색어
- 확인 순서
- 공식 출처 링크
- 정보 제공 고지

## 피해야 할 표현

- 법률상담
- 승소 가능성
- 반드시 위법
- 책임이 확정됨
- 학교가 무조건 배상해야 함
- 처벌 가능성이 높음
- 소송하면 이김
