# 데이터 출처 전략

확인일: 2026-05-30

이 문서는 `GYO6 Law Info`가 공식 원문 중심으로 작동하기 위한 데이터 출처와 연결 순서를 정리한다.

## 기본 원칙

- 법률 자문이나 사건 판단을 하지 않는다.
- 법령, 판례, 행정자료, 학교 현장 지침을 출처별로 구분한다.
- 검색 결과에는 항상 원문 링크와 확인일을 표시한다.
- AI 요약은 원문 내용을 쉽게 풀어 쓰는 보조 기능으로 제한한다.
- 원문이 없거나 출처가 불명확한 내용은 답변하지 않고 추가 확인을 안내한다.

## 보조 출처 후보

- 고용노동부: 근로기준, 산업안전보건, 노동관계 자료
- 안전보건공단: 산업안전보건 해설 자료
- 학교안전공제중앙회: 학교안전사고 관련 안내 자료
- 시도교육청: 지역별 학교폭력, 현장실습, 민원 처리 지침
- 국회법률도서관: 법률 이슈, 입법자료, 판례 검색 보조

보조 출처는 공식 기관 여부, 최신성, 원문 링크, 저작권 조건을 확인한 뒤 연결한다.

## 데이터 연결 순서

### 1단계: 정적 검색 링크

현재 MVP 단계에서는 질문과 주제 사전을 바탕으로 공식 검색 링크를 생성한다.

- 국가법령정보센터 검색
- 법원 판례 검색
- 교육부 자료 확인
- 학교폭력 가이드북 직접 연결

## 출처 정렬 기준

결과 화면은 사용자가 먼저 확인해야 할 출처를 주제별로 다르게 정렬한다. 목적은 많은 링크를 보여주는 것이 아니라, 첫 확인 경로를 줄여주는 것이다.

| 취업·근로계약 | 법령 원문 | 교육부·고용노동부 자료 | 판례 | 전문가 확인 |
| 도제학교 | 교육부·교육청 자료 | 법령 원문 | 안전 자료 | 전문가 확인 |
| 현장실습 | 교육부·교육청 자료 | 법령 원문 | 안전 자료 | 전문가 확인 |

| 중대재해·안전 | 안전 자료 | 법령 원문 | 교육부·교육청 자료 | 전문가 확인 |

| 학생관리·민원 | 교육부·교육청 자료 | 법령 원문 | 판례 | 전문가 확인 |

## 사용자 질문 보강 기준

검색 정확도를 높이기 위해 결과 화면에서 다음 정보를 추가로 물어본다.

- 누가 관련되어 있는가
- 언제, 어디서 발생했는가
- 계약서, 협약서, 공문, 문자, 상담 기록이 있는가
- 학교, 교육청, 산업체, 외부 기관이 이미 어떤 조치를 했는가
- 학생 안전이나 권리 보호가 즉시 필요한가
- 소송, 고소, 고발, 징계, 중대재해처럼 전문가 확인이 필요한 표현이 있는가

중요 사안 표현이 감지되면 일반 요약보다 전문가 확인 안내를 더 먼저 보여준다.

### 2단계: 법제처 Open API

법령 API 키가 준비되면 다음 순서로 붙인다.

1. 법령 목록 조회
2. 법령 본문 조회
3. 조항호목 조회
4. 행정규칙 조회
5. 판례 목록·본문 조회
6. 법령해석례 조회
7. 법령용어 조회
8. 지능형 법령검색 API 검토

현재 로컬 MVP는 `server.mjs`에서 다음 API를 우선 연결한다.

- 법령 목록 조회: `target=law`
- 법령해석례 목록 조회: `target=expc`
- 고용노동부 법령해석 목록 조회: `target=moelCgmExpc`

법제처 인증값은 `.env.local`의 `LAW_OPEN_API_OC`를 기본으로 사용하며, 기존 입력 호환을 위해 `LAW_OPEN_API_KEY`도 함께 인식한다.
법제처 사용자 검증은 신청 도메인 또는 서버 IP와 맞아야 하므로, 서버 호출 시 `LAW_OPEN_API_REFERER` 값을 `Referer`/`Origin` 헤더로 함께 보낸다. 현재 등록 기준 도메인은 `https://gyo6.kr/`이다.
사용자 질문 전문은 외부 법령 검색어로 보내지 않는다. `laws`가 명시되지 않은 경우에도 시스템이 주제별 법령명 후보와 민감정보 없는 짧은 검색어만 만들어 법제처·MCP·공공데이터 검색에 사용한다. 공개 응답 URL에는 `OC`, `serviceKey`, `apiKey` 같은 인증 식별자를 포함하지 않는다.

### 3단계: 판례·행정자료 확장

- 사법정보공유포털 API 활용 가능 범위 확인
- 교육부·교육청 자료 검색 방식 정리
- 고용노동부와 안전보건공단 자료 연결 검토

안전보건공단 자료는 공공데이터포털 일반 인증키로 다음 두 API를 먼저 연결한다.

- 한국산업안전보건공단_국내재해사례 게시판 정보 조회서비스
- 한국산업안전보건공단_안전보건자료 링크 서비스

두 API 모두 로컬 서버에서 호출하고, 브라우저에는 `PUBLIC_DATA_API_KEY`를 노출하지 않는다.

### 4단계: AI 요약

AI 요약은 다음 조건을 만족할 때만 제공한다.

- 원문 제목과 URL이 있다.
- 법령명, 조문, 시행일을 표시할 수 있다.
- 요약과 원문 근거를 분리해 보여줄 수 있다.
- 답변 끝에 정보 제공 안내를 표시한다.

## 결과 화면에 표시할 정보

- 우선 확인할 법령·자료
- 추천 검색어
- 확인 순서

- 정보 제공 고지
