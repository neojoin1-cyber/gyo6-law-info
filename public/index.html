설탕과소금이 경북직업교육연구회, 한국관광교육연구회와 함께 특성화고등학교 선생님과 학생의 성장을 응원하며 필요한 정보와 자료를 안전하고 쉽게 연결합니다. 지침·서식·법조문 자료는 로그인 없이 먼저 확인하고, 학생과 교직원은 상담실에 안전하게 글을 남기며, 관리자는 공식 규정·지침과 관리자 법률정보 AI를 활용해 답변합니다.

기본값

경상북도교육청 기준으로 먼저 봅니다.

교육청을 따로 고르지 않아도 경상북도교육청 기준으로 우선 답변합니다. 실제 소속 교육청이 다르면 질문창에서 바꿔 적용할 수 있습니다.

질문 이해

대상자와 업무영역을 먼저 분리합니다.

학생, 교사, 기간제교원, 행정직, 교육공무직, 사립학교 교직원처럼 적용 규정이 달라지는 기준을 먼저 잡고 답변합니다.

답변 방식

두괄식 답변을 먼저 보여줍니다.

처음 화면에는 결론과 핵심 확인만 간단히 보여주고, 절차·서식·관련 규정은 사용자가 원할 때 아래 버튼으로 더 볼 수 있게 나눕니다.

추가 질문

모호하면 필요한 정보만 다시 묻습니다.

질문 요지가 부족하면 바로 대충 답하지 않고, 신분·기간·장소·업무단계·증빙자료처럼 답변에 꼭 필요한 슬롯만 되묻습니다.

How It Helps

공식 근거

현장 질문을 공식 자료 확인 순서로 연결합니다.

현장실습, 취업지도, 출장·휴가·복무, 학교회계, 학생생활기록, 학교폭력 사안처리처럼 학교에서 바로 판단하기 어려운 질문을 공식 자료 확인 순서로 정리합니다.

사용 방법

조건을 고르고 질문을 적으면 됩니다.

  1. 소속 교육청은 기본적으로 경상북도교육청으로 둡니다.
  2. 대상자와 업무영역을 가능하면 선택합니다.
  3. 질문은 한 문장이어도 괜찮습니다.
  4. 답변 후 필요한 경우에만 관련 규정·절차·서식을 추가로 봅니다.
